# Aula Estrella · Positivos de clase

Web de demostración en **HTML, CSS y JavaScript**, con diseño verde menta.

## Acceso

Contraseña de demostración: `admin1234`.

**Importante:** está escrita en JavaScript y puede consultarse en el código; no es un sistema de autenticación seguro. **No uses nombres ni datos personales reales de alumnos** hasta añadir autenticación segura en el servidor y almacenamiento protegido.

## Funciones

- Añadir y eliminar alumnos (con confirmación).
- Sumar o quitar estrellas, sin valores negativos.
- Buscar por nombre y ver estadísticas.
- Guardar los datos únicamente en el navegador mediante `localStorage`.
- Cerrar la sesión de demostración.
- Diseño adaptable a móviles.

## Uso local

Abre `index.html` en tu navegador. No requiere instalaciones ni dependencias.
